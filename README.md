# Классификация английских текстов по уровню CEFR

Нейронная сеть, которая определяет уровень сложности английского текста по шкале CEFR: **A** (начальный), **B** (средний), **C** (продвинутый).

Проект выполнен в рамках производственной (эксплуатационной) практики — МУ им. С.Ю. Витте, кафедра информационных систем, направление 09.03.03 «Прикладная информатика», профиль «Искусственный интеллект и анализ данных». Руководитель практики — Атаева О.М.

## Зачем это нужно

Сквозная тема моей учёбы — приложение для изучения иностранных языков. Одна из его ключевых функций — подбирать ученику тексты для чтения под его уровень: слишком простые не учат, слишком сложные отбивают желание. Размечать библиотеку текстов вручную нереально, поэтому нужен автоматический классификатор, который по тексту определяет уровень по шкале CEFR.

Эта практика — первый шаг к такому классификатору.

## Данные

[CEFR Levelled English Texts](https://www.kaggle.com/datasets/amontgomerie/cefr-levelled-english-texts) (Kaggle, amontgomerie) — 1494 английских текста с разметкой уровня от A1 до C2.

Шесть уровней укрупнены до трёх классов:

| Класс | Уровни | Текстов |
|---|---|---:|
| A | A1, A2 | 560 |
| B | B1, B2 | 491 |
| C | C1, C2 | 443 |

Датасет скачивается автоматически прямо в коде через `kagglehub`. Копия исходного файла лежит в папке `data/`.

## Как запустить

```bash

cd cefr-text-classification
python3 -m venv venv
```

> Если `kagglehub` запросит авторизацию, нужен API-токен Kaggle (`~/.kaggle/kaggle.json`). На macOS при первом запуске может понадобиться сертификат для загрузки словаря `nltk` — это решается автоматически во второй ячейке ноутбука.

## Ход работы

Ноутбук устроен как последовательная история — каждый шаг опирается на результат предыдущего.

**1. Загрузка и укрупнение классов.** Шесть уровней CEFR сведены к трём. Классы получились сбалансированными (соотношение 1,26 : 1), дополнительная балансировка не понадобилась.

**2. Признаки сложности.** Нейросеть работает с числами, поэтому для каждого текста вычислено 12 признаков: длина предложений и слов, доля длинных слов, лексическое разнообразие и шесть формул читаемости (Флеш, Флеш–Кинкейд, Ганнинг, SMOG, Дейл–Челл, доля трудных слов).

**3. Разведочный анализ.** Диаграммы размаха показали, что большинство признаков монотонно растут от A к C — сильнее всего различает уровни средняя длина предложения (медиана 7 → 16 → 21 слово). Уровни B и C перекрываются сильнее всего. Матрица корреляций показала, что формулы читаемости почти дублируют друг друга (|r| = 0,88–0,99).

**4. Базовые модели.** Прежде чем строить нейросеть, проверено, что дают простые модели (кросс-валидация на 5 частях):

| Модель | Accuracy |
|---|---:|
| TF-IDF (мешок слов) + логистическая регрессия | 0,842 ± 0,049 |
| Признаки сложности + логистическая регрессия | 0,845 ± 0,063 |
| Признаки сложности + случайный лес | 0,861 ± 0,051 |

Слова и структура текста дают сопоставимый результат. Для нейросети выбраны признаки сложности: 12 входов вместо 5000 при той же точности — меньше риск переобучения и понятно, на что смотрит модель.

**5. Нейронная сеть.** Многослойный перцептрон на PyTorch:

```
12 признаков → Linear(64) → ReLU → Dropout(0.3)
             → Linear(32) → ReLU → Dropout(0.3)
             → Linear(3)  → softmax
```

3011 обучаемых параметров, оптимизатор Adam, функция потерь — перекрёстная энтропия, ранняя остановка по валидации. Данные разделены 70 / 15 / 15 (обучение / валидация / тест) со стратификацией, `random_state` зафиксирован.

**6. Результат на тестовой выборке:**

| | Precision | Recall | F1 |
|---|---:|---:|---:|
| A | 0,920 | 0,952 | 0,936 |
| B | 0,797 | 0,797 | 0,797 |
| C | 0,875 | 0,836 | 0,855 |
| **Accuracy** | | | **0,867** |

Лучше всего модель узнаёт начальный уровень, сложнее всего — средний: он граничит с обоими соседями.

**7. Улучшение модели.** Проверено 13 вариантов по трём направлениям:

| Направление | Что менялось | Accuracy |
|---|---|---|
| Гиперпараметры | скорость обучения, dropout, размер пакета | 0,862 – 0,876 |
| Топология | от 1 слоя на 32 нейрона до 3 слоёв (515 – 36 611 параметров) | 0,862 – 0,884 |
| Данные | только 6 простых признаков / признаки + TF-IDF | 0,853 / 0,884 |

Все варианты дали 0,853–0,884, что укладывается в статистическую погрешность теста (±0,022 при 225 текстах). Модель устойчива к настройкам — качество ограничено данными, а не архитектурой. Самая маленькая сеть (515 параметров) не уступила самой большой (36 611), а время одной эпохи растёт с числом параметров.

## Итог

Нейросеть определяет уровень английского текста с точностью **86,7%** при целевом пороге 70%.
