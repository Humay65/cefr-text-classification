# Классификация английских текстов по уровню CEFR

Проект выполнен в рамках эксплуатационной практики (направление 09.03.03 «Прикладная информатика», профиль «Искусственный интеллект и анализ данных», МУ им. С.Ю. Витте). Руководитель практики — Атаева О.М.

## Зачем это нужно

Сквозная тема моей учёбы — приложение для изучения иностранных языков. Одна из его ключевых функций — подбирать ученику тексты для чтения под его уровень: слишком простые не учат, слишком сложные отбивают желание. Размечать библиотеку текстов вручную нереально, поэтому нужен автоматический классификатор, который по тексту определяет уровень по шкале CEFR (A1–C2).

Эта практика — первый шаг к такому классификатору. 

## Задача

Классификация англоязычных текстов по уровню сложности CEFR. Базовая постановка — три класса: **A** (начальный), **B** (средний), **C** (продвинутый). Расширение до шести уровней A1–C2 рассматривается как улучшение.

Целевая метрика — accuracy на тестовой выборке не ниже 70 %, дополнительно precision / recall / F1 по классам и матрица ошибок.

## Данные

[CEFR Levelled English Texts](https://www.kaggle.com/datasets/amontgomerie/cefr-levelled-english-texts) — открытый размеченный датасет с Kaggle. Скачивается в коде через `kagglehub`, в репозитории не хранится (подробнее в [`data/README.md`](data/README.md)).

## Подход

Нейросеть на PyTorch: `Embedding → (Bi)LSTM → Dropout → Linear + softmax`. Функция потерь — cross-entropy, оптимизатор — Adam. Обоснование архитектуры, формулы слоёв и расчёт числа параметров — в отчёте и в ноутбуке.

## Как это развивалось

1. Постановка задачи, выбор датасета, EDA: баланс классов, распределение длин текстов.
2. Очистка и токенизация. Длина предложений и редкость слов — сами по себе сигнал уровня, поэтому вычищаются только явные артефакты.
3. Векторизация, стратифицированное разбиение train / val / test (`random_state` зафиксирован), `Dataset` / `DataLoader`.
4. Базовая модель, обучение с логированием loss / accuracy по эпохам.
5. Улучшения: гиперпараметры (lr, batch size, dropout, early stopping), топология (BiLSTM, размер скрытого состояния), данные (балансировка, предобученные эмбеддинги).
6. Сравнение вариантов на одной тестовой выборке, анализ ошибок между соседними уровнями.

## Как запустить

```bash
git clone https://github.com/<ваш-логин>/cefr-text-classification.git
cd cefr-text-classification
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook notebooks/cefr_classification.ipynb
```

Для скачивания датасета нужен API-токен Kaggle (`~/.kaggle/kaggle.json`). Ноутбук проверен командой **Kernel → Restart & Run All** на локальной машине.
